Quiero hacer una evolución importante del diseño actual de PGA Estudio Digital.

NO quiero crear otra web distinta desde cero y NO quiero volver a cambiar de dirección estética después de esto.

Ya hemos definido la identidad de marca definitiva de PGA y quiero que adaptes el proyecto actual a ella, conservando el contenido y las secciones que funcionan, pero replanteando el lenguaje visual para conseguir exactamente la sensación que describo a continuación.

========================
IDENTIDAD DEFINITIVA DE PGA
========================

PGA Estudio Digital debe sentirse:

PROFESIONAL + HUMANO + NATURAL + CERCANO + ACTUAL.

Las emociones principales que debe transmitir son:

1. CONFIANZA
2. CALMA / TRANQUILIDAD
3. IMPULSO

Quiero que un autónomo, una PYME o el propietario de un pequeño negocio entre en la web y piense:

“Esta persona va a entender mi negocio.”
“Puedo confiarle mi proyecto.”
“Me lo van a poner fácil.”
“Mi negocio puede verse mucho más profesional.”
“Quiero avanzar con esto.”

No quiero una agencia tecnológica fría.
No quiero una web excesivamente corporativa.
No quiero una plantilla genérica de agencia.
No quiero una web experimental de diseñador.
No quiero una copia visual de Excavaciones El Cabo.

Quiero una marca digital con PERSONALIDAD PROPIA.

========================
REFERENCIA VISUAL
========================

Quiero acercar la web actual a una estética con:

- titulares con mucha personalidad
- composiciones modernas
- buena jerarquía visual
- buen uso del espacio
- contraste
- sensación de marca
- pequeños detalles gráficos
- diseño contemporáneo
- ritmo entre secciones

Pero NO quiero convertirla en una web excesivamente editorial.

No abuses de:
- serif
- cursivas
- titulares gigantes
- números decorativos
- líneas horizontales
- bloques que parezcan páginas de revista

Busco un PUNTO MEDIO:

más carácter que una web corporativa tradicional,
pero más claridad y naturalidad que un portfolio editorial.

========================
PALETA
========================

Mantén la identidad:

- ciruela
- lavanda
- crema / blanco roto
- tonos neutros claros

Pero cambia cómo se utilizan.

Los fondos CLAROS deben dominar la web.

El ciruela debe aportar:
- identidad
- contraste
- botones
- titulares
- detalles

El lavanda debe aportar:
- calma
- suavidad
- diferenciación de secciones

No quiero enormes bloques morados uno detrás de otro.

La página debe sentirse más luminosa y tranquila.

========================
TIPOGRAFÍA
========================

Quiero una tipografía moderna con personalidad.

Los titulares deben tener carácter, pero seguir siendo muy fáciles de leer.

Puedes combinar dos familias tipográficas si mejora el diseño, pero evita que toda la identidad dependa de serif + cursiva.

Utiliza cursiva únicamente como detalle muy puntual.

Quiero una jerarquía clara:

titular potente
→ explicación corta
→ llamada a la acción

Los párrafos deben tener un tamaño cómodo y buen contraste.

========================
DISEÑO Y COMPOSICIÓN
========================

Quiero más personalidad visual que en la versión actual.

No quiero que todas las secciones sigan:

título
texto
imagen
título
texto
imagen

Crea ritmo.

Alterna:
- texto + imagen
- imagen + texto
- bloques centrados
- mockups
- pequeñas composiciones visuales
- algún bloque de color
- mucho espacio respirable

Pero sin convertirlo en algo caótico.

El usuario debe poder recorrer la página con tranquilidad.

Aproximadamente quiero un equilibrio:

50% información / 50% experiencia visual.

No interpretes esto como dividir cada sección literalmente por la mitad.

========================
FOTOGRAFÍA
========================

ESTO ES MUY IMPORTANTE.

Quiero imágenes MUCHO MÁS NATURALES.

No quiero imágenes que parezcan generadas específicamente para combinar con la paleta.

No quiero:
- oficinas perfectas
- paredes lavanda artificiales
- escritorios preparados
- personas mirando a cámara
- sonrisas falsas
- apretones de manos
- poses corporativas
- modelos que parezcan de stock
- escenas futuristas
- imágenes evidentes de IA

Quiero fotografía de aspecto DOCUMENTAL.

Ejemplos:

- un autónomo trabajando realmente
- una pequeña empresaria revisando algo en su portátil
- una conversación natural sobre un proyecto
- alguien enseñando su negocio
- una persona viendo su nueva web
- manos trabajando
- pequeños negocios reales
- situaciones cotidianas

Luz natural.
Gestos naturales.
Imperfección controlada.
Nada excesivamente preparado.

Las imágenes deben transmitir:

“esto podría ser mi negocio”.

No repitas fotografías.

Cada fotografía debe contar algo.

========================
EL MENSAJE DEBE SER MUY CLARO
========================

La web debe explicar rápidamente QUÉ HACE PGA.

PGA crea y mejora páginas web para negocios.

No quiero que el visitante necesite leer cinco párrafos para entenderlo.

Utiliza:

TITULARES CORTOS.
TEXTOS CORTOS.
IDEAS CLARAS.

Evita jerga técnica.

No quiero mensajes genéricos como:

“Llevamos tu negocio al siguiente nivel.”

Habla de cosas concretas:

- verte profesional
- explicar bien lo que haces
- enseñar tus servicios
- generar confianza
- facilitar que contacten contigo
- tener una web que funcione bien en móvil
- disponer de una presencia digital que represente realmente tu negocio

El protagonista de la web debe ser EL CLIENTE.

PGA es quien le ayuda a conseguirlo.

========================

PARA QUIÉN.
QUÉ puede conseguir.

CTA principal:

“Ver proyectos”

No quiero un enorme bloque morado ocupando toda la primera pantalla.

Utiliza composición, tipografía, imagen y espacio para crear impacto.
